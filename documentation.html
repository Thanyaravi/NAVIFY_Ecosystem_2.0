1. Executive Summary

NAVIFY 2.0 is an advanced assistive navigation and emergency telemetry ecosystem designed for visually impaired individuals. The system integrates low-power edge artificial intelligence with physical sensory hardware, enabling autonomous spatial orientation, obstacle proximity recognition, and instantaneous multi-channel emergency distress broadcasting.

The software architecture spans edge computer vision running YOLOv11 with a proprietary CANIE Geometric Disambiguation filter, continuous spoken voice feedback synthesized via the Web Speech & Web Audio APIs, a 360° ultrasonic radar scope, and an emergency response center capable of reverse-geocoding real GPS coordinates into street addresses and transmitting one-tap alerts via WhatsApp, SMS, and Email to assigned caregivers.

3. Detailed Breakdown of Developed Modules

3.1 Edge AI Object Detection & CANIE Geometrical Disambiguation

  • YOLOv11 & MobileNetV2 Pipeline: Real-time computer vision operating at 30+ FPS, detecting everyday obstacles: persons, vehicles, chairs, doors, stairs, phones, and bottles.
  • CANIE Aspect-Ratio Filter (Bottle vs. Remote Disambiguation): Standard object detectors frequently misclassified vertical water bottles as TV remotes. We engineered a geometrical heuristic layer analyzing the bounding box aspect ratio (height / width ≥ 1.6) and spatial density, reliably resolving the object as a bottle with directional spatial cues ("Bottle ahead on left").
  • Proximity & Spatial Mapping: Automatically divides the field of view into directional sectors (Left, Center, Right) and distance thresholds (Very Close < 0.8m, Close < 1.5m, Mid-Range < 2.5m).

3.2 Spoken Audio Feedback & Acoustic Synthesizer (audioService.js)

  • Web Speech API: Spoken real-time announcements with custom voice pitch and rate, notifying the user immediately when hazards enter their path.
  • Web Audio API Acoustic Synthesizer: Built-in multi-frequency audio synthesizers producing directional sonar pings, hazard alert chimes, and emergency klaxons without external audio file dependencies.
  • Non-Blocking Speech Queue: Intelligent deduplication prevents audio stuttering and speech overlapping during high-density obstacle detection.

3.3 360° Circular Sonar Radar HUD (UltrasonicRadar.jsx)

  • Interactive cybernetic canvas displaying a continuous 360° radar sweep with 0.5m, 1.0m, and 2.0m safety distance rings.
  • Translates ultrasonic sensor telemetry into color-coded hazard blips (Green = Safe, Amber = Caution, Red = Immediate Obstacle).

3.4 SOS Center, Fall Simulation & Emergency Caregiver Notification (SOS.jsx)

  • Giant Emergency Distress Trigger: Large, high-contrast SOS button with ripple animations, spoken vocal alarm, and immediate distress telemetry broadcast.
  • Dedicated Fall Simulation Button: A prominent ⚡ Simulate IMU Fall Event — BNO085 Test button allowing direct verification of fall logic without needing to drop physical hardware.
  • Hardware Fall Sensor Listener: Listens to browser and cane devicemotion acceleration ($> 32\text{ m/s}^2$) with a 15-second debounce filter.
  • Real Live Location via Reverse Geocoding: Automatically fetches real GPS coordinates from navigator.geolocation and queries OpenStreetMap Nominatim to resolve actual human-readable street names, neighbourhoods, and postal codes (e.g., Rajanukunte, Bengaluru, Karnataka). Institutional fallback set to SVIT Campus coordinates (13.16335° N, 77.56278° E).
  • Emergency Contacts & 1-Tap Broadcast Suite: Clean contact cards featuring a single, aligned green call button (tel:...) for Vikram Sir and Tejas P. The Emergency Broadcast Modal provides 1-tap notifications:
    • WhatsApp Broadcast: Pre-fills live GPS coordinates, battery level, time, and Google Maps pin.
    • SMS Direct Dispatch: Sends distress packet via native messaging app.
    • Email Dispatch: Formats formal distress notification directly to mentor email addresses.
  • Persistent SOS History: Maintains a chronological audit trail of all manual and fall triggers in localStorage with live synchronization to the FastAPI backend.

5. Technical Stack & Hardware Specifications

Frontend Software Stack

  • Framework: React 18 (Create React App + CRACO)
  • Styling: Tailwind CSS, PostCSS, Radix UI
  • Animation: Framer Motion (0.15s crossfade)
  • Icons: Lucide React (Explicit modular imports)
  • Speech & Audio: Web Speech API + Web Audio API
  • Reverse Geocoding: OpenStreetMap Nominatim
  • Deployment: Vercel Global Edge Network

Hardware & Edge Vision Stack

  • Vision Model: Ultralytics YOLOv11 Nano (yolo11n.pt)
  • Disambiguation: CANIE Aspect-Ratio Geometric Filter
  • Ultrasonic Sonar: HC-SR04 Rangefinder (2cm–400cm)
  • IMU Sensor: BNO085 9-DoF Accelerometer & Gyroscope
  • GPS Telemetry: u-blox NEO-M9N GNSS Receiver
  • Backend: FastAPI, Python 3.11, Uvicorn, PyMongo
  • Repository: GitHub CI/CD syncing master & main
